# 阅读界面设计

参考 Goodnotes 的文档操作层级：[官方界面说明](https://support.goodnotes.com/hc/en-us/articles/13682253498767-Improved-User-Interface)。阅读顶部直接从文档标签开始，移除独立品牌栏、App 名称与宣传语。

1. 文档标签栏：左侧返回书库，中间显示可切换、可关闭的文档标签，右侧加号导入 PDF。选中标签有背景与下划线。标签顺序保存到本机，重启恢复；关闭标签保留书库及笔记。
2. 操作栏：撤销、重做、翻页、跳页、自动回复开关、AI 页边栏和文档菜单。保存与处理状态放在菜单内，处理中显示进度；失败时显示重试入口。
3. 笔工具栏：钢笔、圆珠笔、画笔、高光笔、橡皮；三个粗细预设与精确滑块；黑、蓝、红快捷色和包含其他颜色的调色板。窄窗口允许横向滚动。

固定工具栏不覆盖书页，不再显示浮动笔盒或底部操作栏。关闭最后一个标签显示简洁的文档导入空态。AI 页边栏保留，窄窗口通过面板打开。这里只实现当前 App 已支持的操作，没有加入无效的套索、搜索或导出按钮。

沿用用户图标的奶油白、蓝色与浅紫色调，工具选中态使用淡蓝背景。原始图标仍用于安装图标与无文档空态，不占用阅读顶栏。资源位置为 `AskInk/Assets.xcassets`。

## 验证边界

对真机与模拟器架构进行无签名编译，并运行既有书写算法测试。当前机器没有可运行的 iPad 模拟器，因此横竖屏布局、标签切换后的真实笔迹恢复、弹出调色板和 Pencil 操作仍需在设备上确认。
