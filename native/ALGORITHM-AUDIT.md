> 历史研究记录，不代表当前实现。当前版本已改为自定义 UIKit 书写与内置 v6 small 本机 OCR，见 [现行设计](AI-DESIGN.md)。


此文件保留首次审计的基线，下面的代码行为与行号不是最新实现。后续手写模块已加入时间／空间分组、后台笔迹存储、Apple／Google 轨迹识别、PaddleOCR v5/v6 对照和测试样本评估，见 [当前实现说明](../handwriting/README.md)。尚无个人字迹或真机手感基准，因此研究与效果验证的限制仍成立。

## 结论

当前是可编译的原生基础版，并非已经完成论文驱动优化的算法产品。上一轮主要核对平台/API 文档和产品资料，没有系统评估研究论文、复现模型或运行真实笔迹基准。本轮才补充以下文献审查。编译成功与 36 项后端测试通过不能证明书写手感、中文识字准确率或阅读问答质量。

## 候选研究及采用边界

### 1. 书写：1€ Filter

速度相关低通滤波在慢速时降低抖动，快速时降低延迟，是 CHI 2012 的经典基线，不是最新论文。只在自定义书写引擎实验中比较；直接叠加到 PencilKit 的已处理笔迹上可能增加延迟或改变汉字形状。
作者与算法页：https://gery.casiez.net/1euro/

### 2. 识字：轨迹与图像联合编码

A Transformer Based Handwriting Recognition System Jointly Using Online and Offline Features（2025）同时编码图像和 (x,y,pen) 轨迹。论文主要实验为英语/越南语等，不能将结果直接当成中文整句识别保证。
https://arxiv.org/abs/2506.20255
https://arxiv.org/html/2506.20255v1

Rotation-free Online Handwritten Character Recognition Using Linear Recurrent Units（ICPR 2026；2026-09 更新）使用 Sliding Window Path Signature 与 LRU。实验是数字、大写英文字母、中文部件的子集，不能直接提供完整潦草中文句子识别。
https://arxiv.org/abs/2602.01533

建议先对比专业在线笔迹引擎与现有图像识字方案，再决定是否有理由自训联合模型。保留原始笔迹是必要条件，但不等于已经利用了这些信号。

### 3. 扫描书：专门的文档解析模型

PaddleOCR-VL-1.5（2026）研究 0.9B 文档解析与扫描、倾斜、形变等鲁棒性；DeepSeek-OCR 2（2026）研究按语义重排视觉 token 和复杂版面。应作为扫描 PDF 解析候选，不因文档指标高就宣称能认好用户的潦草手写，或能在 iPad 流畅端侧运行。
https://arxiv.org/abs/2601.21957
https://arxiv.org/abs/2601.20552

### 4. 阅读问答：视觉检索与可控定位

ColPali（ICLR 2025）用页图像多向量与 late interaction 做检索，可作为含图表/扫描页的全书视觉检索基线。它不直接解决短问题“为什么”的段落指代；仍需笔迹位置、选定原文和对话状态。
https://arxiv.org/abs/2407.01449
https://arxiv.org/html/2407.01449v6

Designing and Evaluating AI Margin Notes in Document Reader Software（CHI 2026）发现研究参与者偏好集成的 AI 页边批注与手动选取原文。可指导加入手动选段、自动候选调整和回复原文绑定。研究没有证明 AI 介入本身提高阅读理解，不应把便利性直接包装成学习效果。
https://arxiv.org/abs/2509.09840
https://arxiv.org/html/2509.09840v3

### 5. 识字的“猜词”风险

Visual Merit or Linguistic Crutch? A Close Look at DeepSeek-OCR（2026）通过语义扰动研究语言先验依赖。它研究的是特定模型和任务，不是对所有视觉模型或新版 OCR 2 的结论；对本项目的启发是单独测试否定词、生词和不符合常识的原句，不能仅看识别文字是否通顺。
https://arxiv.org/abs/2601.03714

## 验收与下一步

1. 建立用户真实问题的标注集，另设不同写作者的独立测试集，避免用调参样本报告准确率。
2. 对比本机 Vision、专业在线识字、云端图像识字；测 CER、整句准确率、关键否定词保留、拒识/误识与修正次数。
3. 加入手动问题区域和原文选段；固定规则仅作为候选定位，记录目标段落命中率。
4. 将扫描正文解析、文本/视觉全书检索独立比较；返回稳定页/段 ID，校验引用确实存在。
5. 分别测模型回答依据、幻觉、拒答、耗时 p50/p95 与 token 成本；再决定模型路由和是否自训。
6. Pencil 真机测书写延迟、缩放对齐、漏笔、长时间性能与主观手感。

以上研究候选尚未集成、复现或证明优于当前基础版。本轮只审计和记录，没有以未经验证的方案替换代码。
