# AskInk — iPad 原生独立版 0.1

此目录是独立 iPad App，项目已移除网页版与 Node.js 服务。运行时无需电脑服务。

## OpenAI 接入：只在 iPad App 设置中填写

1. 打开 App 的“设置 → OpenAI · iPad 独立连接”。
2. 填写自己的 OpenAI API Key，以及账户可调用的模型 ID。模型需支持 Responses API、图片输入、结构化输出及当前请求参数。
3. 点击“保存”。API Key 保存在 iPad 本机 Keychain，模型 ID 保存在 App 本机设置。
4. 写下问题 → 停笔默认 2 秒 → 本机识别 → 自动结合附近正文回答，无需点击按钮或逐次确认。

调用链：**iPad App → https://api.openai.com/v1/responses → iPad App**。
发送识别的问题、附近正文及其裁剪图像、同页最近四条问答；不上传整本 PDF。
阅读、书写和内置 PaddleOCR v6 small 识字可离线运行；问 OpenAI 时 iPad 需要联网。
模型 ID 默认值仅是项目配置，不代表账户一定有该模型权限。

## 已实现

- SwiftUI + PDFKit 连续阅读、双指缩放、翻页和跳页。
- 自定义 Pencil 画布：钢笔、圆珠笔、画笔、荧光笔、整笔橡皮、颜色、粗细、撤销和重做；使用 PKDrawing 保存笔迹。
- 固定三层顶部：文档标签页、操作栏、笔工具栏；标签切换与关闭，重启恢复打开的标签，关闭标签不删除书籍。
- 粗细快捷预设与滑块、颜色快捷选择与调色板、稳定度和压感设置；黑、蓝、红、黄、绿、粉及自定义颜色均支持高光笔。
- 高光笔写出的字参与手写识别；长横向高光作为正文标记，优先按近期附近标记定位提问参考。
- OCR 使用深色细线快照，保留原始彩色笔迹。默认停笔 2 秒后自动识别并发送 AI；设置中可调整等待时间或暂停自动回复。
- PDF 导入 App Documents，按页保存 PKDrawing，恢复书籍、页码与问答。
- 按笔画时间和空间分组，选择最近一段、前后段或本页全部。
- 随 App 内置的 PaddleOCR 本机识字，笔迹变化后不应用过时识别结果。
- 根据笔迹位置选择附近同栏正文，按附近正文自动回答，回复可展开查看引用正文。

## 构建与安装（开发步骤）

用 Xcode 打开 `native/AskInk.xcworkspace`，选择自己的 Apple 开发者 Team 和 iPad 后构建安装。换开发电脑时在 native 目录执行 `pod install`，安装 ONNX Runtime、Yams 和 OpenCV 依赖。最低 iPadOS 17。
开发电脑用于构建安装；安装后的阅读、识字和 OpenAI 问答不依赖开发电脑运行。

## 验证边界

文档与原生连接设置已按独立运行方式更新。实际 API 调用需用户在设备上填写密钥后验证，本次未调用付费模型。
Pencil 手感、缩放对齐、双栏与扫描书、长时间保存、中文手写准确率仍需真机验证。
暂未实现全书检索、套索选题、iCloud 同步、标准批注 PDF 导出和旧版备份迁移。两版数据独立保存。

已通过真机/模拟器架构无签名编译、13 项书写/分组算法测试。已检查最终 App 包内的 det/rec ONNX 与 YAML 都存在。使用相同权重的开发机 ONNX 检测→裁剪→识别链路识别出合成印刷行“为什么不是这样？AI 123”；直接将未裁剪整图送入识别阶段时漏了 I，说明检测裁剪的重要性。以上均不是个人手写准确率或真机延迟验证。

## 高光提问的使用方式

高光标记正文后，在旁边用钢笔、圆珠笔、画笔或高光笔写出问题，停笔后自动识别并回答。仅高光划线时提示写出问题，不把线条猜成文字。高光长横线采用几何规则区分，120 秒内、垂直距离 120 点以内的最近相关标记优先定位；短标记、复杂圈画与跨段落标记可能需要调整范围或确认指代。

本次高光提问修改已通过模拟器无签名编译及 18 项原生算法测试；个人手写识别率与 Apple Pencil 手感仍需真机验证。

## 停笔自动回复

默认开启，停笔 2 秒后自动识别新写的那句话并调用已配置的 AI；不弹确认窗口。继续书写重新计时，识别期间笔迹发生变化则丢弃旧识别。已发送笔画按书籍和页码记录，不在下一句话中重复提交。回答期间新笔迹等待当前请求完成；翻页后的回复仍保存到原页，切换书籍后的回复仍保存到原书。高光划线和擦除不单独提问。失败不循环调用，可使用“重试回复”；实际 API 连接及手写识别仍需在设备上验证。

## 书写修复与检查

已修复笔带端点填充抵消、跨 64 段分块漏更新、系统取消丢笔迹、自动回复回调顺序、高光颜色及工具图标。检查细节与真机验证范围见 [WRITING-AUDIT.md](WRITING-AUDIT.md)。最新原生算法与几何回归共 24 项通过。

## 当前识别与多模态架构

- iPadOS 27：优先 `PKStrokeRecognizer`，直接读取选中的 `PKDrawing`。检查所选语言是否在 `supportedLanguages` 中；默认简体中文，并在支持时加入英语。
- 旧系统、不支持的语言、Apple 返回空结果：回退内置 PaddleOCR v6。Apple 不返回置信度，本项目不伪造置信度。
- 两种识别均失败或没有文字时，保留空转录与原始笔迹；支持视觉输入的 AI 仍可处理手写问题。
- 自动提问同时发送转录草稿、原始手写裁剪图、附近正文文字和正文裁剪图。两张图片分别标注问题和参考材料，数学符号及混写不再只能依赖 OCR。
- 手写图保留所选 PKDrawing 的形状、颜色和宽度；另有细黑线图仅用于 PaddleOCR。回复保留转录、笔迹图、识别来源、版本及 Apple 搜索返回的笔迹位置，支持查看原始问题。旧问答仍可读取。
- 在“本机识别”中设置主要语言，如 `zh-Hans` 或 `en`。兼容 API 如果关闭图片发送，手写请求会明确提示选择视觉模型，避免静默丢失公式。

识别与笔迹位置的实际准确率仍需 iPad 真机验证；同时发送两张图会增加图片输入用量。本次不宣称数学识别已经可靠。
