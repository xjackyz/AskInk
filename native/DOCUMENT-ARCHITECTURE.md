# AskInk：阅读优先，AI 理解文档

**A Pencil-first reader with document-aware AI.** PDF 是第一个格式，不是领域模型。

## 已实现的主链路

`PDFDocumentAdapter → DocumentGraph → 本机 FTS5 / 可用的系统句向量 → ContextPlanner → ContextPacket → AIReadingPipeline → 流式回答 → 内容锚点与 AIThread`

- `Document` 取代原来的 `Book` 数据类型。`book.json` 与旧偏好键继续读取，缺失格式默认为 PDF。
- `ContentBlock` 包含文档 ID、稳定内容 ID、正文、章节路径、阅读顺序、位置、前后块、内容类型与可选向量。段落包含句子 ID，句子指回段落并保存 UTF-16 文本范围。
- `ContentLocation` 区分固定页和流式定位器。`ContentAnchor` 包含文档/内容 ID、位置与引用文本；旧 `{x,y}` 锚点继续解码。流式锚点无需坐标。
- `Annotation` 定义 note / highlight / underline / aiAnswer 语义。AI 回答可从持久化会话投影为锚定批注。普通笔迹继续由 PencilKit 保存；完整的笔迹语义事件库尚未迁移。
- `AIThread` 与 `AITurn` 保存一条问题的会话，不把同页其他问题作为对话历史。
- `DocumentAdapter` 定义导入提取边界。目前只有 PDF 的实际适配器。领域模型、FTS 与上下文规划不依赖 PDFKit；PDF 渲染、导出、原文截图及坐标转换仍位于原生 PDF 阅读边界。

## 导入与本地索引

打开/导入文档后后台建立索引，原生文本优先，缺少文本的页使用本机 Vision OCR。PDF 目录存在时保留章节层级；无目录时不编造章节。多行正文组装为段落候选，由 NLTokenizer 再分句。

`document-index-v2.json` 保存图、提取行、未识别页和可用向量；`document-search-v2.sqlite` 保存 SQLite FTS5 索引。中文用双字词，英文用词搜索。段落用于检索，句子保留结构和精确文本范围，避免把同一内容重复送入摘要/索引。

语义检索使用 Apple NaturalLanguage 的句向量，向量标记语言和模型版本，仅比较同模型、同维度的向量。系统不支持的语言退回 FTS；不自动下载模型或改用云端。FTS 排名与余弦排名通过 reciprocal rank fusion 合并。目前语义搜索遍历本机向量，未引入 ANN 数据库。

内容 ID 在同一文档版本内稳定；文件变化会重新建立图，尚未实现跨编辑版本的引用重定位。PDF 段落分组和阅读顺序为版面启发式；复杂多栏需真机文档验证。句子的框沿用父段落框，文本范围准确性依赖提取/OCR结果，尚非逐字几何框。

## 调用 AI 前的规划

先定位划线/高光/选中句，再取所在段落、相邻段落和相关前文；加入有来源的文档记忆、最近会话及有限历史摘要。普通问答不发送全文。明确选择全文总结时，才逐块处理所有可识别正文，并缓存中间摘要。

预算按 UTF-8 字节做保守文本估算，并分别限制选中原文、空间上下文和检索段落。历史预留空间，避免长段落挤掉追问所需的上文。该估算不等于供应商计费 token，不含系统提示、JSON 字段/转义、问题、图像及输出；实际使用量读取响应 usage。证据只在 ContextPacket 中传一次。

默认限制到当前阅读位置。记忆若包含后续来源，会被排除；允许后文时可放宽。生成摘要始终带来源 ID，且不能代替原文证据。检索不到材料时标记索引未就绪或证据不足，不能假装阅读全文。

当前问答管线支持所配置供应商的流式回答；引用只允许本次提供的来源 ID。模型路由在客户端配置，尚未部署图中提出的独立 Backend / 服务端 Model Router。没有进行真实付费模型请求验证。

## 明确尚未完成

- Readium EPUB 阅读器、DOCX 导入适配器及其原生笔迹布局。
- 表格、图、脚注与引文的专门结构提取。ContentType 已留类型，不能据此声称已解析这些对象。
- 完整的笔迹语义批注存储与跨文件版本重定位。
- 后端身份验证、服务端模型路由和部署。
- 真机 OCR/手写/定位准确率、系统模型可用性、摘要质量及实际 token 节省量。

核心回归覆盖旧数据与坐标解码、EPUB locator 规划、父子/前后关系、中文持久化 FTS、语义模型隔离、阅读范围、历史和证据预算，以及请求中不重复发送正文。

验证记录：74 个 Swift 回归测试通过；通用 iOS Simulator 目标构建成功。未启动模拟器 UI，也未进行真机或付费 API 测试。
